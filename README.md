# Proyecto CarSales 🚗

Este proyecto es un sistema de gestión para una concesionaria de autos usados. Permite registrar clientes, empleados, vehículos, ventas y compras. Además, incluye funcionalidades como visualización de fichas técnicas, estadísticas, reportes y más.

---

## 🧰 Tecnologías utilizadas

- HTML, CSS, Bootstrap
- JavaScript, AJAX
- PHP
- MySQL (XAMPP / MySQL Workbench)
- Git & GitHub
- Visual Studio Code

---

## 🔧 Requisitos

- XAMPP (PHP + MySQL)
- MySQL Workbench (opcional para importar la base)
- Navegador web moderno (Chrome, Firefox, etc.)

---

## 🗃️ Base de datos

Incluye un backup de la base de datos llamado:

/database/backup.sql


Para importar la base:

1. Iniciá Apache y MySQL desde XAMPP.
2. Abrí **phpMyAdmin** (http://localhost/phpmyadmin).
3. Creá una base de datos nueva con el nombre que quieras (ej: `car_sales`).
4. Importá el archivo `backup.sql` desde la pestaña **Importar**.
